# Parking Lot and Accuracy

Supporting data. Attached to 02 Entropy - a useful wrong turn.

Compression and semantic density are stage metaphors, not Shannon-entropy measurements. A short prompt does not uniquely encode a complete correct program.

During ordinary model inference, context changes activations and attention patterns, not the trained parameters. Meaning can be distributed; there need not be one neuron or coordinate for a human concept.

An autoencoder is an explanatory analogy, not a description of an LLM's full mechanism. Hypothetical latent-code experiments have no results yet.

C# var preserves static typing. A named type may help local reading without adding information absent from the initializer. Evaluate actual changes rather than arguing from token count.

SQL has formal semantics; an agent can guess unstated product choices. BNF describes grammar, not the whole semantics of a language. Punched cards are a medium, not an abstraction level.

Tests provide evidence about checked properties, not universal proof of intent. Intent documentation does not eliminate code, technical decisions, runtime constraints, or review.

The PDF's learning-study shorthand needs precision: the reported scores are 50% versus 67%, not a universally measured 17% decline in expertise.[4] Productivity claims remain dated and task-specific.[2][3]

# From Opcode to Intent

Working materials for a twenty-minute, two-host talk about the move from expressing implementations to formulating and verifying intent.

Start with the [enriched talk plan](Talk%20Brief.md).

## Contents

- `Enriched PDF Plan.txt` — standalone English plain-text plan.
- `Talk Map.canvas` — the fixed-layout Obsidian trunk-and-branches map.
- `Trunk/` — thirteen numbered sections in speaking order.
- `Branches/` and the supporting root notes — evidence, preparation, and optional deviations attached to specific sections.
- `Sources/Original background.pdf` — the unchanged source PDF.

The plan follows the source PDF's historical sequence and enriches it with the co-host discussion. Hypotheses and proposed demonstrations are labelled; they are not presented as completed experiments.

## Obsidian

Open this repository folder as a vault, or clone it into an existing vault. Open `Talk Map.canvas` for the visual structure. Follow the numbered trunk downward; green branches provide supporting data and orange branches offer optional detours. Use backlinks to return from a branch.

The native Graph view is force-directed; Canvas preserves the intended spatial reading order. Obsidian-specific wikilinks and Canvas are best viewed in Obsidian rather than GitHub.

Local Obsidian settings, workspace state, OS files, and environment credentials are excluded from version control. No automatic Git synchronization is configured.

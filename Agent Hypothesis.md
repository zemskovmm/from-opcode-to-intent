# Agent Hypothesis

Optional deviation. Attached to 13 Intent is the new working unit.

Your alternative to frontend/backend/UI silos is an agent responsible for a business scenario: onboarding, charging a customer, making a payment, or recovering a deleted note. It keeps the outcome, edge cases, and risks together and can delegate technical subtasks.

Technical roles may be the same model with different instructions and context, not independent specialist minds. Tools, training, permissions, and configuration can nevertheless create meaningful differences; “same base model” does not prove identical competence.

Current context and attention limits are a strong motivation for decomposition. Reliably huge context could reduce some need to split work, but parallelism, independent review, permission separation, fault isolation, and coordination costs remain relevant.

“We gave one model six job titles and finally automated the org chart.”

Hypothesis, not established result. Compare layer-oriented and scenario-oriented assignments on the same changes and budgets; check whole-scenario correctness, missed cases, handoff cost, and regressions.

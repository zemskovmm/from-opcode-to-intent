# B08 Semantic representations

Optional deviation. Attached to 08 The short prompt has a long context.

Your intuition is that meaning is distributed rather than stored in a guaranteed “UI neuron” or “key neuron.” In English, “key” plus “door” suggests one sense; “key” plus “music” suggests another. This is an accessible contextual example, not a claim about a single neuron's response.

At ordinary inference time, context changes activations and attention, not the trained weights. Individual representation coordinates need not be directly interpretable as human concepts.

An image autoencoder offers a visual analogy: an input is compressed through a bottleneck representation and reconstructed. It is tempting to think of a composite portrait with properties such as pose or face shape, but those need not align to separate editable axes in an ordinary model.

Tone, formality, romance, fear, or code structure may be useful concepts for probing representations. This does not establish a literal semantic control panel inside a language model. An LLM is not simply that image autoencoder applied to text.

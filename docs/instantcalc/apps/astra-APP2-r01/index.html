About this total

Every valid calculation line is counted, including references and subtotals. Variable-table values are not added separately. Exact values are summed before rounding.

    A little help.

    Tap a line and start calculating. Answers appear as you type.

    • Use +, −, ×, ÷, decimals and parentheses.
    • $1 uses line 1’s result. You can reference earlier lines only.
    • Open Variables to edit named numbers. Use price × 3 or insert a name with its Use button. Names are case-sensitive.
    • Total adds every valid line, including subtotals. Tap the included/excluded count for details. Variables are not added separately.
    • … means there’s a little more to type. Tap an indicator for details.
    • ≈ means the display is rounded. Calculations keep the exact value.
    • Copy a result with the icon beside it. The approximation mark is omitted.
    • Your lines save in this browser, on this device. Clearing browser data removes them.

    Using a keyboard? Enter moves to the next line. ↑ and ↓ move between lines.

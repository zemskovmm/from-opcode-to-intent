    A QUICK INTRODUCTION

    Room for your everyday math.

    Choose any of the ten lines, then type or use the keypad. Your result appears as you go. An ellipsis means keep typing; select an indicator for an explanation below the worksheet.

    Connect your calculations

    Use Reference to insert an earlier line, or type $1 + $2. Changes flow through automatically. A reference waits if its source is empty or unfinished.

    Reuse named numbers

    Open Variables to add and edit numbers in a separate table. For example, name a value rate, then enter @rate × 4 in a line. Use inserts it for you. Both names and values can be edited with the on-screen keys. Names must be unique; duplicate names and unfinished values pause calculations that use them.

    The total at the bottom

    All valid line results count, including subtotals: lines of 10, 20, and $1 + $2 total 60. Blank, unfinished, invalid, and waiting lines are excluded. Select the included/excluded count to see why. Variables are not additional calculation lines.

    A few useful expressions

    (12.5 + 3) × 2
    31
    2^3 · power
    8
    sqrt(81) · square root
    9
    200 × 10%
    20
    200 + 10%
    200.10

    Percent always means divided by 100. Use parentheses for grouping; multiplication needs × or *. Powers come before a leading minus: −2^2 is −4.

    Made to pick up where you left off

    Your expressions save in this browser on this device, even halfway through a calculation. Opening the app may need internet. Clearing browser data removes saved work.

    Results show integers or two decimal places. Calculations use the unrounded values with standard floating-point precision. Tiny values can display as 0.00. Keyboard: Enter or ↓ for the next line, ↑ for the previous line.
